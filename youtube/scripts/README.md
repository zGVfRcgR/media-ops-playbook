# YouTube 台本保存ディレクトリ

このディレクトリには、YouTube 動画の台本を保存する。

## 使い分け

- `draft/` — 下書き
- `review/` — レビュー中
- `published/` — 確定済み

## ファイル名例

- `2026-10-06_short-term-investing_v1.md`
- `2026-10-06_short-term-investing_v2.md`
- `2026-10-06_short-term-investing_final.md`

## 基本ルール

- 1本の動画につき1ファイルを原則とする
- 版管理は `v1`, `v2`, `final` などで行う
- 保存時はテーマと日付を含める
- 公開前にレビュー済みのファイルは `review/` か `published/` に移す
