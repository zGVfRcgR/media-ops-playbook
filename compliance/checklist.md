# コンプライアンス確認チェックリスト

## 内容確認
- [ ] 元記事が特定できるか
- [ ] 要約に誤りがないか
- [ ] 断定しすぎた表現がないか
- [ ] 誤解を招く言い回しがないか

## 金融・税務・法務
- [ ] 個別の投資助言に見えないか
- [ ] 税務判断を断定していないか
- [ ] 法律判断を断定していないか
- [ ] 「合法」「問題ない」と言い切っていないか

## 著作権・権利
- [ ] 他人の画像や音声を無断利用していないか
- [ ] 引用が必要なら出典があるか
- [ ] 肖像権や商標権のリスクがないか

## 投稿安全性
- [ ] 炎上リスクが高すぎないか
- [ ] コメントで誤解されそうな箇所がないか
- [ ] 必要なら人間確認を入れたか

## 最終判断
- [ ] 公開してよい
- [ ] 修正が必要
- [ ] 人間の専門家レビューが必要
